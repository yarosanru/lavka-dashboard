# Заказы из Лавки

Интерактивный дашборд истории заказов на Vue.js 3.5.22 и D3.js 7.9.0.

Отдельная домашняя работа: [Неделя 6 — график вовлечённости в фитнес-программу](https://yarosanru.github.io/lavka-dashboard/fitness/). [Описание графика и выводы](fitness/README.md).

## Просмотр

Откройте `index.html` в браузере. Данные и библиотеки встроены в файл; подключение к интернету не требуется.

## Возможности

- Последние 24 месяца, вся история, отдельный год или диапазон дат.
- Число заказов, расходы и средняя скидка за последний месяц периода с сравнением с предыдущим месяцем.
- Три диаграммы месячной динамики основных метрик, включая месяцы без покупок.
- Топ товаров одновременно в штуках и рублях; выбор рейтинга по количеству или расходам.
- Подсказка товара с количеством, расходами и историей фактической цены за штуку.
- Список категорий с числом заказов, количеством товаров, расходами и средней скидкой; фильтр категории.
- Поиск товаров и номеров заказов, фильтр статуса и сортировка таблицы.

## Данные и расчёты

Источник — предоставленный файл `данные.xlsx`, лист «Заказы по дате».
Период: 03.09.2021–24.08.2026. 2 079 строк позиций объединены в 480 уникальных заказов.

- 455 доставленных заказов; 25 отменённых.
- Расходы включают только доставленные заказы и составляют 415 354 ₽.
- Товары: 393 990 ₽. Доставка и упаковка: 21 364 ₽.
- Средний чек — сумма доставленных заказов / их количество.
- Скидка — (цена без скидки − цена со скидкой) × количество, только по доставленным заказам.
- Средняя скидка — среднее процентных скидок на единицу товара с весом по количеству; товары без скидки учитываются с нулём. Доставка и упаковка исключены.
- Цена в истории товара — сумма расходов на товар / количество за месяц; показаны только месяцы покупок.
- Время доставки — разница между временем создания и доставки с учётом перехода через полночь.
- Количество товаров исключает доставку и упаковку.
- По умолчанию показаны сентябрь 2024 — август 2026: последние 24 месяца отсчитываются от последнего месяца данных. Август неполный, по 24.08.2026.
- Фильтр периода меняет все показатели. При выборе категории суммы и товары ограничены этой категорией, а число заказов учитывает заказы с её товарами. Список категорий сохраняет все категории выбранного периода.
- Поиск, статус и сортировка меняют только таблицу.

Адреса доставки исключены из опубликованных данных. Исходный Excel в репозиторий не включён.

## Файлы

- `index.html` — автономный готовый дашборд.
- `data.json` — данные без адресов доставки.
- `app.js` и `template.html` — исходники.
- `vendor/` — локальные библиотеки Vue и D3.
- `build.py` — сборка автономного файла командой `python3 build.py`.
