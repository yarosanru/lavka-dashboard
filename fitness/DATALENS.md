# Данные фитнес-программы для DataLens

Загрузите `fitness-datalens.xlsx`, лист **Просмотры**. Первая строка содержит заголовки, каждая из следующих 3 755 строк — один реальный просмотр. В таблице 101 участник, 80 тренировок и 24 поля. Дополнительные поля подготовлены как значения, поэтому загрузка не зависит от пересчёта Excel-формул.

## Загрузка

1. В DataLens создайте подключение **Файлы**, нажмите **Загрузить файлы** и выберите Excel-файл.
2. Выберите лист **Просмотры**, включите использование первой строки как заголовков.
3. Проверьте типы полей, создайте подключение и датасет на его основе.

Альтернатива — `fitness-datalens.csv`: кодировка **UTF-8 с BOM / utf-8-sig**, разделитель **точка с запятой**, десятичный разделитель в данных — точка, заголовки в первой строке. Даты записаны в формате `YYYY-MM-DD`.

## Типы полей

- **Строка:** ID просмотра, ID пользователя, Код тренировки, День, Тип, Тренер, Тренировка по расписанию, Группа участника. Сохраняйте код `02-06` как строку, а не дату.
- **Дата:** Дата открытия, Дата просмотра.
- **Дробное число:** Длительность, Длительность просмотра, Глубина. Для глубины задайте отображение в процентах: исходное 0,67 означает 67%.
- **Целое число:** остальные поля. Неделю, позицию тренировки, порядок дня и свойства участника используйте как измерения, когда они задают группировку.

Подробный словарь всех полей — `fields.json`. У 1 902 просмотров оценка отсутствует: это пустое значение, не ноль.

## Показатели в датасете

Создайте поля с формулами:

| Показатель | Формула DataLens |
| --- | --- |
| Число просмотров | `SUM([Просмотров])` |
| Активные участники | `COUNTD([ID пользователя])` |
| Просмотры на участника программы | `SUM([Просмотров]) / MAX([Участников в программе])` |
| Средняя глубина | `AVG([Глубина])` |
| Доля досмотров не менее 95% | `AVG([Досмотр не менее 95%])` |

У поля **Участников в программе** всегда 101: его нельзя суммировать. Знаменатель метрики вовлечённости остаётся 101 при выборе отдельной недели или тренировки. Деление на активных участников отвечает на другой вопрос.

## Проверка загрузки

- Без фильтров: число просмотров — **3 755**, уникальных участников — **101**, уникальных кодов тренировок — **80**.
- Неделя 1: **484** просмотра, **101** активный участник, **4,7921** просмотра на участника.
- Неделя 10: **324** просмотра, **60** активных участников, **3,2079** просмотра на участника.
- Тренировка 02-06: **35** просмотров, средняя глубина около **67,2%**.

Для обзора выбирайте **Неделя** и **Тренировка по расписанию**, показатели выше и **Тренер** для цвета. Подпись расписания начинается с 01–08, чтобы разминки разных дней располагались отдельно и в правильном порядке.

Таблица содержит исходные частицы данных и свойства для построения чартов. HTML-композиция с отдельными заполненными фигурами опубликована на GitHub Pages; импорт файла сам по себе не создаёт такую композицию в DataLens.

## Интерпретация

Неделя относится к программе, а не к календарной неделе просмотра. Группа участника описывает просмотренные недели в пределах файла и не устанавливает причину прекращения просмотров. Длительности сохранены в единицах исходного файла: единица явно не указана.

Источник — предоставленный Excel-файл «Онлайн-тренировки, 10 недель--954768701.xlsx», лист «Просмотры». Добавленные поля рассчитаны из этих же записей. Вспомогательный лист исходника с числом тренировок по участникам не добавлялся как новые просмотры.

Документация: [подключение к файлам](https://yandex.cloud/ru/docs/datalens/operations/connection/create-file), [агрегатные функции](https://yandex.cloud/ru/docs/datalens/function-ref/aggregation-functions).
