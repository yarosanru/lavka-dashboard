# Неделя 6. Фитнес-программа

[Открыть график и выводы](https://yarosanru.github.io/lavka-dashboard/fitness/)

3 755 просмотров, 101 участник, 80 тренировок. Недели идут слева направо; восемь рядов сохраняют тип и день тренировки. Один кубик — один просмотр. Столбики сложены снизу вверх от общей линии основания; десять кубиков в полном ряду, одинаковый размер частиц во всём графике. Цвет — тренер, заполнение — глубина. Верхний ряд повторно показывает те же просмотры в недельной сумме.

- [Описание и выводы](HOMEWORK.md)
- [График PNG](fitness-homework.png)
- [Страница HTML](index.html) — также доступна для скачивания на сайте.

Публичная страница содержит только обезличенные распределения глубины с шагом 0,1 процентного пункта. Исходные ID, персональные даты и связи между просмотрами участников не публикуются. D3.js 7.9.0 встроен; служебные библиотеки оболочки загружаются с CDN. Наведение и нажатие открывают подсказку; Tab и стрелки позволяют изучать просмотры с клавиатуры. На узком экране недели разбиваются на последовательные панели.
