# Неделя 6. Фитнес-программа

[Открыть график и выводы](https://yarosanru.github.io/lavka-dashboard/fitness/)

Один график по учебным данным: 3 755 просмотров, 101 участник и 80 тренировок. Недели × восемь тренировок; отдельный просмотр — прямоугольник, цвет — тренер, заполнение — глубина. Публичные фигуры восстановлены из обезличенных распределений глубины с шагом 0,1 процентного пункта. Исходных ID участников и просмотров, персональных дат и связей между просмотрами в странице нет. D3.js 7.9.0 и агрегированные распределения встроены в index.html. Служебные библиотеки оболочки загружаются с CDN.
