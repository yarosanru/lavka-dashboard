Как считаются показатели

Средняя скидка — среднее значение (цена без скидки − фактическая цена) / цена без скидки по единицам товаров, с учётом количества. Товары без скидки входят с нулевой скидкой; доставка и упаковка исключены. Для товара с нулевой исходной ценой учитывается нулевая скидка. Месяц без товаров показан как отсутствие данных, а не нулевая скидка.

Траты включают только доставленные заказы. При выборе категории учитываются только её позиции без доставки и упаковки. Число заказов считается по уникальным номерам, а не по строкам товаров. Цена в подсказке — средняя фактическая цена за штуку в месяцы покупок; месяцы без покупок не заполняются вымышленными ценами. Названия товаров сохраняются как в источнике.
